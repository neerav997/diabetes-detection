# 🩺 Diabetes Risk Predictor

A machine learning web app that predicts the likelihood of diabetes from
basic health metrics (glucose level, BMI, age, etc.), built with
**scikit-learn** and **Streamlit**.

## How it works

1. `train_model.py` trains a `RandomForestClassifier` on the Pima Indians
   Diabetes dataset and saves the trained model + feature scaler.
2. `app.py` is a Streamlit web app that loads the saved model and lets a
   user enter their own values to get a live prediction.

## Setup

```bash
# 1. Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate      # on Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt
```

## Get the real dataset (important)

This repo ships with `diabetes.csv` generated by `generate_sample_data.py` —
**synthetic data, for testing the pipeline only.**

For your actual project, download the real dataset and replace the file:

1. Go to https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
2. Download `diabetes.csv`
3. Replace the file in this folder with it (same column names, so nothing
   else needs to change)

## Train the model

```bash
python train_model.py
```

This prints accuracy/precision/recall and saves `model.pkl` + `scaler.pkl`.

## Run the app

```bash
streamlit run app.py
```

This opens the app in your browser at `http://localhost:8501`.

## Deploy it for free (to get a live link for your resume)

1. Push this folder to a public GitHub repo
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub
3. Click "New app", pick your repo and `app.py` as the entry point
4. Deploy — you'll get a live `https://yourapp.streamlit.app` link

## Model details

- **Algorithm:** Random Forest Classifier (200 trees, max depth 6)
- **Features:** Pregnancies, Glucose, Blood Pressure, Skin Thickness,
  Insulin, BMI, Diabetes Pedigree Function, Age
- **Preprocessing:** invalid zero-values in medical fields replaced with
  the column median; features standardized with `StandardScaler`
- **Note:** this is an educational demo, not a certified medical tool
